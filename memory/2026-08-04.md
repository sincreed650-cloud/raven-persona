# 2026-08-04 — Setup MiniMax + Security primer di OpenClaw PC

## 🎯 Yang dibahas

### 1. Diagnosa fresh install OpenClaw di PC bos
- Bos install baru OpenClaw 2026.7.1-2 di Windows 11 (10.0.26200)
- Default model: `gpt-5.5` (OpenAI Codex runtime)
- Provider MiniMax belum ke-config → `config get providers` not found
- Path yang benar: `models.providers` (bukan root `providers`)

### 2. Setup MiniMax — rekomendasi: Coding Plan / OAuth
- `openclaw onboard --auth-choice minimax-global-api` (API key path)
- `openclaw onboard --auth-choice minimax-global-oauth` (Coding Plan, OAuth)
- Buat bos (light tinkering, personal install) → **OAuth/Coding Plan** lebih cocok
  - Subscription flat → predictable cost
  - Setup via OAuth → no API key management
  - Built-in usage tracking
  - Ada diskon 10% via referral link di `providers/minimax.md`
- Model ref: `minimax/MiniMax-M3` (API key) atau `minimax-portal/MiniMax-M3` (OAuth)

### 3. Security doc breakdown (`docs/gateway/security`)
- **Trust model**: 1 gateway = 1 trust boundary. Bukan multi-tenant.
- **Threat model**: urutan = identity → scope → model. "Bot nurut" = risiko utama, bukan exploit teknis.
- **DM policies**: pairing (default, paling aman) → allowlist → open → disabled
- **Sandbox**: Docker (full) atau `agents.defaults.sandbox` (built-in). 
- **Secrets on disk** locations — perlu tahu untuk backup planning
- **Anti-patterns**: bind 0.0.0.0 no-auth, dmPolicy open, elevated buat陌生人, browser profile personal

### 4. PC OpenClaw auto-respond (audit context)
- PC OpenClaw detect host: Win 11 workstation, embedded mode
- Minta 4 context Q + ijin read-only checks
- Commands: `openclaw security audit --deep`, `gateway status --deep`, `doctor`, `systeminfo`, `Get-NetFirewallProfile`, `Get-BitLockerVolume`
- Bos → confirm + jawab context → PC jalanin

## 🪪 Raven identity setup di PC

Bos mau PC OpenClaw juga jadi "Raven" (matching identity gw). Cara:
1. Copy `IDENTITY.md`, `SOUL.md`, `USER.md`, `AGENTS.md`, `TOOLS.md` dari workspace ini ke `~/.openclaw/workspace/` di PC
2. Optional: `openclaw agents set-identity` (kalau command-nya ada)
3. Save `memory/2026-08-04.md` ini biar continuity
